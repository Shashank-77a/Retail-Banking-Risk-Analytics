# Retail-Banking-Risk-Analytics
End-to-end data analytics project featuring Excel-based statistical modeling and a Power BI dashboard for retail banking risk intelligence.

* **Note:** This is a portfolio project created for practice and skill demonstration. The dataset used is a synthetic, 
AI-generated dataset designed to simulate real-world retail banking scenarios.

## Project Objective
The goal of this project was to execute an end-to-end data analytics workflow—starting from raw data manipulation and statistical analysis in Excel, 
and culminating in an interactive, business-ready Power BI dashboard. This project simulates a real-world business case: monitoring bank portfolio health, 
analyzing customer churn, and identifying credit risk.

## Core Skills Demonstrated
* **Data Engineering (Excel):** Data cleaning, formatting, and feature engineering.
* **Logical Formularization:** Extensive use of logical functions (IF, AND, OR) to create custom risk tiers and categorizations.
* **Statistical Analysis:** Generating descriptive statistics to analyze data distribution, variance, and outliers.
* **Data Visualization (Power BI):** Interactive dashboard design, DAX formatting, and geospatial mapping.

## What I Did
### Step 1: Excel (Data Prep & Math)
Before making any charts, I spent time in Excel getting the data ready:
* **Formulas:** I used logical formulas (like IF, AND, OR) to group customers into different risk categories (like High Risk or Low Risk) based on their data.
* **Descriptive Statistics:** I used the **Data Analysis Toolpak** (under the Data tab) to quickly run a descriptive analysis. This gave me a summary of the mean, median, standard deviation, and variance for columns like 'Annual Income' and 'Account Balance'.

### Step 2: Power BI (Visualization)
Once the Excel file was ready, I connected it to Power BI to build the dashboard. I created visuals to show:
* **Key Numbers:** Total deposits, average credit score, and overall churn rate.
* **Customer Behavior:** A chart showing how the number of products a customer has affects whether they leave the bank.
* **Risk:** A scatter plot comparing credit scores to loan balances.
* **Locations:** A map showing where the deposits are coming from globally.

## Tools I Used
* **Microsoft Excel:** Data Analysis Toolpak, Logical Formulas.
* **Microsoft Power BI:** Dashboard creation and data visualization.
